Bu public repo yalnız statik beta dağıtımı içindir. Ana kaynak kod private `Hakk-m_Al-` reposunda tutulur.

- Güncel geliştirme adresi: https://raw.githack.com/saygilicihan4-lgtm/-ecek-/main/index.html
- V0.10 sabit CDN sürümü: https://rawcdn.githack.com/saygilicihan4-lgtm/-ecek-/0bf3999986245dfc0a250ea0da26866aadc2c7d6/index.html

## V0.10 özellikleri
- Yerel vaka sınıflandırma
- 2026 tüketici rota mantığı
- THH / BTK / SHGM / TBB resmî kanal bağlantıları
- İsteğe bağlı AES-GCM şifreli yerel kasa
- PBKDF2-SHA256 anahtar türetme
- Kanıt dosyasını yüklemeden SHA-256 + metadata özeti
- JSON yedekleme ve içe aktarma
- Uygulama açıkken yerel hatırlatma bildirimi
- PWA / offline uygulama kabuğu
- Sunucuya vaka verisi gönderimi yok
